iOS Safari iPhone · iPad

Safari on iOS doesn't allow dragging links to bookmarks. Follow these steps instead:

  1. Tap the Copy button below to copy the bookmarklet code.
  2. In Safari, bookmark any page (tap the share icon → Add Bookmark).
  3. Open Bookmarks → find the bookmark you just created → tap Edit.
  4. Clear the URL field and paste the copied code. Save.
  5. Now visit Metal Archives, open bookmarks, and tap MA Mobile Fix.
Tip: The bookmarklet only applies for the current page load. You need to tap it once on each new page you visit, or after a full refresh. For a persistent solution, use the .user.js file with Tampermonkey (available on the iOS App Store as a Safari extension).

Orion Browser iOS

Orion supports the Stylus and Tampermonkey extensions natively. Use metal-archives-mobile.css in Stylus, or metal-archives-mobile.user.js in Tampermonkey — no bookmarklet needed.
